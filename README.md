# Project

一个纯前端的个人任务清单网页，用原生 HTML、CSS 和 JavaScript 实现。
无需后端、无需构建工具、不依赖任何外部 CDN 或在线资源。

## 运行方法

方式一：直接双击 `index.html`，用浏览器打开即可。

方式二：如果浏览器对 `file://` 下的本地存储有限制，可以起一个静态服务器：

```bash
# Python 3
python3 -m http.server 8000

# 或者 Node.js
npx serve .
```

然后浏览器访问 <http://localhost:8000>。

## 已实现的功能

### 1. 添加任务
- 在输入框中填写内容，点击「添加」或按 `Enter` 均可新增任务。
- 输入为空或只有空格时不会添加，并在输入框下方给出提示。

### 2. 标记完成 / 删除
- 勾选任务左侧的复选框即可标记为已完成，同时文字显示删除线。
- 点击任务右侧的 `×` 删除该条任务。
- 删除做了防误触处理：删除后列表会重排，双击或连点同一个位置时，落在同一坐标上的后续点击会被忽略，不会连带删掉上移过来的其他任务。点击别的位置（即有意删除）不受影响。
- 另有「清除已完成」按钮，可一次性删除全部已完成任务（没有已完成任务时自动隐藏）。点击后会弹出确认框，说明将删除多少条，只有点「清除」才会真正删除；点「取消」或按 `Esc` 都不会删除任何任务。

### 3. 筛选
- 「全部」「未完成」「已完成」三个筛选项，各自显示对应的数量徽标。
- 当前选中的筛选项会高亮。
- 在「已完成」筛选下新增任务时会自动切回「全部」，保证新任务立即可见。

### 4. 本地存储
- 任务数据和完成状态保存在浏览器 `localStorage`（键名 `todo-app.tasks.v1`），刷新或重开页面后依然存在。
- 读取时会校验并归一化数据：损坏的 JSON 或非法条目会被安全丢弃，不会导致页面崩溃。
- 若浏览器禁用了本地存储，页面仍可正常使用，只是数据不会被保存。

### 5. 交互反馈
- 输入框获得焦点时高亮边框；校验失败时边框转红并提示原因。
- 任务行悬停、按钮悬停/按下、键盘焦点都有对应的视觉反馈。
- 顶部实时显示汇总文案（共多少条、还剩多少条未完成）。
- 列表为空时按当前筛选显示对应的空状态文案。
- 新增任务带有轻微的进入动画，并遵循 `prefers-reduced-motion` 设置。
- 支持深色模式（跟随系统 `prefers-color-scheme`）与窄屏布局。

### 6. 其他
- 所有任务文本通过 `textContent` 渲染，用户输入不会被当作 HTML 执行。
- 提供了无障碍支持：表单标签、`aria-labelledby`、`aria-pressed`、`role="alert"` 等。
- 每个任务的勾选框通过 `aria-labelledby` 关联到本行的任务文字，无障碍名称形如「标记为已完成 写项目文档」，屏幕阅读器可以区分不同任务；相关联的 id 由计数器生成，保证唯一。
