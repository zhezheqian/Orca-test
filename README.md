# Project

## 个人任务清单（网页版）

一个零依赖的纯前端任务清单应用：原生 HTML + CSS + JavaScript，无后端、无外部 API、无 CDN 或在线资源，离线可用。

### 运行方法

无需安装依赖、无需构建，两种方式任选：

1. **直接打开**：双击项目根目录下的 `index.html`，或将其拖入浏览器窗口。
2. **本地静态服务（推荐）**：在项目根目录执行

   ```bash
   python3 -m http.server 8000
   ```

   然后浏览器访问 <http://localhost:8000>。

### 已实现功能

- **添加任务**：输入内容后按回车或点击「添加」；内容为空或只有空格（含全角空格）时不会添加，输入框会抖动并提示。
- **标记完成**：点击任务左侧的圆形复选框，可在「已完成 / 未完成」之间切换，完成的任务显示删除线与灰色文字。
- **删除任务**：点击任务右侧的「删除」按钮，删除时有退出动画。
- **筛选**：顶部提供「全部 / 未完成 / 已完成」三个筛选标签，标签上实时显示对应数量。
- **本地持久化**：任务保存在浏览器 `localStorage`（键名 `task-list.tasks.v1`），刷新或重开页面后仍然存在；存储数据损坏或非法时自动降级为空清单，不会导致页面崩溃。
- **即时反馈**：顶部摘要实时显示剩余未完成数量，全部完成时给出提示；新增任务有入场动画。
- **无障碍与细节**：全部操作支持键盘，配合 `aria-live` 播报操作结果；跟随系统的浅色 / 深色主题；适配窄屏与 `prefers-reduced-motion`。

### 项目结构

```text
.
├── index.html   页面结构
├── styles.css   样式（含浅色 / 深色主题）
└── app.js       交互逻辑与本地存储
```
